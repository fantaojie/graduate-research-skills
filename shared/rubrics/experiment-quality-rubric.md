# Experiment Quality Rubric

| Criterion | Strong | Weak |
| --- | --- | --- |
| Hypothesis link | Every experiment tests a specific claim. | Experiments are disconnected from claims. |
| Baseline fairness | Baselines use comparable data, settings, and metrics. | Baselines are unfair or unclear. |
| Metric fit | Metrics match the research question. | Metrics are convenient but misleading. |
| Ablation value | Ablations isolate important components. | Ablations are cosmetic. |
| Reproducibility | Seeds, hardware, data splits, and code plan are visible. | Key settings are missing. |
