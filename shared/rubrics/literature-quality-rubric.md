# Literature Quality Rubric

| Criterion | Strong | Weak |
| --- | --- | --- |
| Coverage | Includes recent, relevant, and representative papers. | Misses central papers or subfields. |
| Metadata integrity | Venue, year, tier, code, and metrics are verified or marked unknown. | Metadata is guessed. |
| Synthesis | Compares methods, assumptions, and evidence. | Lists papers one by one. |
| Recency | Prioritizes the specified time range and current surveys. | Uses stale literature without reason. |
| Traceability | Search strings and sources are recorded. | Search path cannot be reconstructed. |
