# Extensions

This directory reserves space for future research skills that are useful but not part of the first MVP.

## Candidate Skills

| Candidate | Purpose |
| --- | --- |
| `research-review-response` | Reviewer comment analysis and response letter drafting. |
| `research-submission-check` | Submission checklist, formatting checks, and venue readiness. |
| `research-thesis-writing` | Thesis chapter planning and long-form thesis structure. |
| `research-reproducibility` | Environment, seed, artifact, and reproduction planning. |
| `research-figure-planning` | Figure and table narrative design. |
| `research-poster-slides` | Poster and defense slide planning. |
| `research-grant-proposal` | Funding proposal and project application writing. |

## Graduation Criteria

A candidate can move into `skills/` when it has:

- Clear trigger conditions.
- A focused workflow with one primary research task.
- Required outputs that can be validated.
- Quality checks and failure modes.
- At least one realistic invocation scenario.
